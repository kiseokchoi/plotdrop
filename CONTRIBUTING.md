# Contributing to PlotSift

Thank you for helping improve PlotSift. Bug reports, reproducible sample images, documentation fixes, and focused pull requests are welcome.

## Development setup

1. Install Node.js 22 or later and the stable Rust toolchain.
2. Run `npm ci`.
3. Run `npm run standalone:dev` for the desktop application, or `npm run dev` for the local browser version.
4. Before opening a pull request, run `npm run lint`, `npm run desktop:build`, and `npm test`.

Please do not include confidential, copyrighted, or unpublished research figures unless you have permission to share them. Contributions are accepted under the Apache License 2.0.
