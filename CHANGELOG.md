# Changelog

All notable changes to PlotSift will be documented here.

## [Unreleased]

### Added

- Renamed the project from Plotdrop to PlotSift to establish a distinct, searchable identity.

- Tauri-based standalone desktop application packaging.
- Native desktop save dialog for DAT, TSV, and CSV exports.
- GitHub Actions checks and draft release packaging.
- Apache License 2.0 project licensing and contribution documentation.
- Automatic Korean/English interface selection based on the system language, with a persistent manual language override.

## [0.1.0] - 2026-08-28

- Initial research preview with manual point and error-bar extraction, color and brush-assisted extraction, multiple data sheets, editable tabular data, and configurable export delimiters.
